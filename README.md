StaffUp — Smart Staff Request

A React Native app built with Expo that lets restaurant owners submit staffing requests, review booking details, find matching staff, and confirm bookings.

Setup

Make sure Node.js is installed, then open a terminal in the project folder (the folder containing package.json).

1. Install dependencies

npm install --legacy-peer-deps

2. Start Expo

npx expo start

3. Run the app

Scan the QR code with Expo Go on your phone.

Or press a to open an Android emulator.

Useful Commands

npm test                 # Run unit tests
npm run typecheck        # Check TypeScript
npm run smoke            # Test the sample requests
npx expo start -c        # Restart Expo with a cleared cache

Tech Stack

React Native, Expo, TypeScript

Expo Router

React Context + reducer

Rule-based parser with optional Claude integration


## 📌 About the Project

**StaffUp — Smart Staff Request** is a mobile application built with React Native and Expo that helps restaurant owners find suitable staff based on their requirements.

### ✨ Features

* Create staff requests using natural language.
* Review and edit booking details.
* Match staff based on skills, availability, distance, and reliability.
* Confirm bookings and track request status.

### 🛠️ Tech Stack

* React Native
* Expo
* TypeScript
* Expo Router
* React Context API

### 🎯 Objective

To simplify restaurant staff booking through smart request parsing and staff matching.
